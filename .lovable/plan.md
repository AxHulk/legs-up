## В чём проблема с «пропадающими инструкторами»

FTP и хостинг тут ни при чём — данные тянутся не из файлов, а из базы (`supabase.from("instructors")`). Причина в логике компонентов:

В `src/components/site/Team.tsx` (стр. 32), `Directions.tsx` (стр. 29) и `Schedule.tsx` (стр. 54) стоит:

```ts
if (team.length === 0) return null;
```

`useQuery` при первом рендере возвращает `data = []` (наш дефолт) и `isLoading = true`. Из-за `length === 0` секция мгновенно убирается из DOM. Если ответ приходит за 50–100 мс — пользователь успевает увидеть блок. Если сеть медленная, кэш React Query протух, или запрос моргнул сетевой ошибкой (CORS/таймаут/блокировщик) — блок не появляется вовсе. На видео именно это: при «удачной» загрузке секция «Инструкторы» есть, при «неудачной» — её просто нет, а соседние секции склеиваются.

Дополнительный риск: якорь `#team` в шапке ведёт в никуда, если секция не отрисована — клик «Инструкторы» просто не скроллит.

## Что меняем

1. **`src/components/site/Team.tsx`**
   - Брать `isLoading` и `isError` из `useQuery`.
   - Возвращать `null` **только** если `!isLoading && !isError && team.length === 0` (реально пустая таблица). Иначе всегда рендерить секцию с заголовком и `id="team"`, а вместо карточек на время загрузки показывать 5 скелетонов (нейтральные плашки в стиле сайта, без покупных библиотек).
   - При ошибке — тихий фолбэк: заголовок + короткая фраза «Список инструкторов временно недоступен, попробуйте обновить страницу», чтобы якорь и SEO‑контент сохранялись.
   - Добавить `retry: 2` и `staleTime: 5 * 60_000` в `useQuery`, чтобы реже моргало между переходами.

2. **`src/components/site/Directions.tsx`** и **`src/components/site/Schedule.tsx`**
   - Та же правка: не скрывать секцию во время загрузки, скелетон вместо карточек, мягкий фолбэк при ошибке. Для `Schedule` оставляем уже существующее поведение «нет занятий» (показываем сообщение), но не убираем секцию целиком, пока идёт первая загрузка.

3. **Меню в `src/components/site/Header.tsx`** — проверил, всё корректно:
   - На главной ссылки `#about / #directions / #team / #schedule / #contacts` ведут на соответствующие секции.
   - На внутренних страницах (`/ceny`, `/pilates-reformer`, `/aero-yoga`, `/zdorovaya-spina`) тот же массив превращается в `/#about`, `/#team` и т. д. — это рабочий паттерн: происходит переход на главную и автоскролл к якорю. Менять не нужно.
   - Единственная неявная проблема — клик по «Инструкторы», когда секция скрыта из‑за пункта 1. После фикса исчезнет.

4. **Не трогаем**: запросы к базе, RLS, тексты, дизайн, SEO‑страницы, цены.

## Технические детали

- Скелетон сделаем локальным компонентом в каждом файле (div с `bg-sand/60 animate-pulse rounded-2xl`), без добавления зависимостей.
- Условие рендера:
  ```ts
  const hasData = team.length > 0;
  const showSkeleton = isLoading && !hasData;
  if (!isLoading && !isError && !hasData) return null;
  ```
- React Query уже настроен в `main.tsx` — глобально менять конфиг не будем, опции задаём прямо в хуках, чтобы не зацепить другие места.
