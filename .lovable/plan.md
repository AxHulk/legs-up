## Цель
Подключить твой аккаунт YClients к сайту, чтобы посетители могли записываться в реальном расписании салона, а ты видел все брони в одном месте (в YClients).

## Какие есть способы интеграции

YClients даёт три варианта — у каждого свои плюсы:

**1. Виджет онлайн-записи (рекомендую как основной)**
- YClients генерирует ссылку и embed-код в личном кабинете (раздел «Онлайн-запись» → «Сайт компании»).
- Это готовая форма: выбор услуги → инструктора → даты → времени → ввод имени/телефона → SMS-подтверждение.
- Подключается за 5 минут, ничего не нужно программировать, все брони автоматически попадают в твой YClients и в расписание сотрудников.
- Минус: дизайн виджета — фирменный YClients, не на 100% совпадёт со стилем сайта (хотя цвета настраиваются).

**2. Прямые ссылки на запись**
- Каждая услуга / филиал / сотрудник имеет уникальную ссылку вида `https://n123456.yclients.com/...`.
- Можно ставить такие ссылки на кнопки «Записаться» — открывается форма YClients (модалкой или новой вкладкой).
- Это компромисс: меньше визуального присутствия YClients, чем встроенный виджет.

**3. API-интеграция (самописная форма)**
- Используем YClients Booking API: твоя форма на сайте сама опрашивает доступные слоты и создаёт запись через API.
- Максимальный контроль над дизайном — выглядит как родная часть сайта.
- Минус: дороже по разработке, нужны API-ключ партнёра + токен пользователя, поддерживать сложнее (SMS-подтверждение, ошибки слотов и т.д.).

## Где на сайте это разместить (мои рекомендации)

```text
Hero ──── кнопка «Попробовать бесплатно» → открывает виджет YClients
         (сейчас она скроллит к контактам — заменим на запуск виджета)

Направления ─ на каждой карточке кнопка «Записаться»
              → ссылка на услугу в YClients (вариант 2)

Расписание ── у каждого занятия кнопка «Записаться»
              → уже есть поле booking_url в БД, туда вставляешь
                YClients-ссылку из админки — работает без кода

Инструкторы ─ кнопка «Записаться к инструктору»
              → ссылка на сотрудника в YClients

Контакты ──── форма-заявка остаётся как «свяжитесь со мной»
              (для тех, кто не хочет сам записываться через виджет)
              + дублирующая кнопка «Открыть онлайн-запись»

Header ────── кнопка «Записаться» в правом верхнем углу
              → запускает виджет в модалке
```

## Что предлагаю сделать

**Этап 1 — быстрый (рекомендую начать с него):**
1. Добавить в админ-панель в «Настройки» одно поле — «Ссылка на виджет YClients» (одна общая на весь сайт).
2. Сделать переиспользуемый компонент `<BookingButton>`: открывает YClients либо в модалке (iframe), либо в новой вкладке.
3. Подключить эту кнопку в Hero, Header, Контактах.
4. В расписании уже есть `booking_url` — будешь вставлять прямые ссылки на сеансы из YClients (на каждое занятие отдельно), и кнопка «Записаться» сразу заработает.
5. В админке для Направлений и Инструкторов добавить опциональное поле `yclients_url` → если указано, кнопка «Записаться» ведёт туда.

**Этап 2 (опционально, позже):**
- Полная API-интеграция: при создании занятия в админке оно автоматически создаётся и в YClients; брони с сайта идут через API. Это требует получения партнёрского `Authorization Bearer` токена в YClients и больше работы.

## Технические детали (для меня)

- Виджет YClients поддерживает встраивание через `<script>` и `iframe`. Готовый embed-код берётся в ЛК YClients → Онлайн-запись.
- Для модалки используем простой Dialog с iframe (`src=https://w123456.yclients.com/...`).
- Никаких секретов на этом этапе не нужно — публичная ссылка виджета безопасна.
- На этапе 2 API-токен YClients нужно будет положить в Lovable Cloud secrets и звать API через server function.
