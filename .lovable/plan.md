## Что меняем

Сейчас в `src/components/site/Contacts.tsx` обе CTA-кнопки («Записаться на занятие» и «Купить абонемент») открывают один и тот же `BookingDialog` с базовым URL YClients (`https://n2043963.yclients.com`). Нужно, чтобы кнопка абонементов вела на `https://o18441.yclients.com/subscriptions`.

## Реализация

1. **`src/components/site/Contacts.tsx`**
   - Добавить константу `SUBSCRIPTIONS_URL = "https://o18441.yclients.com/subscriptions"`.
   - Завести второе состояние `subscriptionsOpen` (или общий стейт с типом `"booking" | "subscriptions" | null`).
   - Кнопка «Купить абонемент» → открывает модал с `url={SUBSCRIPTIONS_URL}`.
   - Кнопка «Записаться на занятие» → как сейчас, `url={bookingUrl}`.
   - Рендерить соответствующий `<BookingDialog url=... />` в зависимости от выбранного варианта.

2. **(Опционально) заголовок модала** — `BookingDialog` сейчас всегда показывает «Онлайн-запись». Можно прокинуть пропс `title` (по умолчанию «Онлайн-запись», для абонементов — «Покупка абонемента»), чтобы пользователь понимал, что открылось. Если не хотите трогать `BookingButton.tsx` — оставим как есть.

## Технические детали

- Никаких изменений в backend / Supabase / админке. URL абонементов хардкодим в компоненте (отдельный филиал YClients, не связан с `yclients_url` из `app_settings`).
- `BookingDialog` уже умеет принимать любой `url` через props — переиспользуем без правок (кроме опционального `title`).
